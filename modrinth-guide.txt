Modrinth is an open-source Java-only modding platform supporting Forge, Fabric, Quilt, and NeoForge — no fake buttons, and it shares ad revenue with creators.

⚡ Quick Start
Search the mod → check MC version & loader → Versions tab → Download → place .jar in .minecraft/mods → launch with the matching loader profile. Or use the free Modrinth App for auto-install.

📥 Steps
1. Find a mod on modrinth.com.
2. Confirm the MC version, loader (Forge/Fabric/Quilt/NeoForge), and environment (Client/Both).
3. Versions tab → find the matching file → Download (mods save as .jar, packs as .zip).
4. Open .minecraft: Windows Win+R → %appdata%\.minecraft · macOS Cmd+Shift+G → ~/Library/Application Support/minecraft · Linux ~/.minecraft
5. Create a lowercase "mods" folder if missing and drop the .jar in; .zip packs go in resourcepacks or saves/<world>/datapacks.
6. Launch with the matching loader profile — the mod appears in the Mods menu.
7. Easiest route: install the free Modrinth App (modrinth.com/app) — it manages versions and dependencies automatically.

❗ Common Problems
· Mod doesn't work → check loader (Fabric ≠ Forge), MC version, and the Relations tab for dependencies.
· Game crashes on launch → remove mods one at a time; confirm they all match one MC version.
· Downloaded a .zip instead of .jar → that's correct for resource/data packs — place it accordingly.
· Not sure which loader → check your launcher profile name.

⚠️ Warnings
· Java Edition only — no Bedrock support.
· Never double-click .jar files — place them in the mods folder.
· Always check Relations for required dependency mods.
· Only download from modrinth.com; avoid repacks. The Modrinth App is free — never pay imposters.

❓ FAQ
Q: Does Modrinth support Bedrock? A: No, Java only.
Q: Do I need an account? A: No — browsing and downloading are free.
