Modrinth Download Guide

Modrinth is an open‑source modding platform for Java Edition only, supporting Forge, Fabric, Quilt, and NeoForge. It has no fake download buttons and shares ad revenue with creators.

---

⚡ Quick Start
Search mod → check MC version & loader → click Versions → click Download (.jar for mods, .zip for packs) → place .jar in .minecraft/mods → launch with correct loader profile. Or use the free Modrinth App for auto‑install.

---

📥 DOWNLOAD STEPS

1. Go to modrinth.com – search or browse by category.
2. Open the project page – check description and images.
3. Verify compatibility: Minecraft version, mod loader (Forge/Fabric/Quilt/NeoForge), and environment (Client/Both).
4. Click the Versions tab – find the file matching your version and loader.
5. Click Download – file saves as .jar (mod) or .zip (resource/data pack).
6. Open your .minecraft folder:
   · Windows: Win+R → %appdata%\.minecraft
   · macOS: Cmd+Shift+G → ~/Library/Application Support/minecraft
   · Linux: ~/.minecraft
7. Create a mods folder (lowercase) if missing – drag the .jar into it. For .zip packs: place in resourcepacks or saves/world/datapacks.
8. Launch Minecraft with your mod loader profile (Forge/Fabric/etc.) – mods appear in the Mods menu.
9. Easiest: Download the free Modrinth App from modrinth.com/app – it handles dependencies, versions, and installs automatically.

❗ COMMON PROBLEMS

Problem Solution
Mod doesn't work Check loader matches (Fabric ≠ Forge). Verify MC version. Check Relations tab for dependencies (Fabric API, etc.).
Game crashes on launch Read crash report – remove mods one by one. Ensure all mods are for the same version.
App can't connect Check internet, restart app, or reinstall from official site.
Search not finding mods Use filters (loader/version/category). Clear browser cache.
Downloaded .zip instead of .jar Keep .zip – place in resourcepacks or datapacks folder.
Don't know which loader I have Check launcher profile name – it shows Forge, Fabric, Quilt, or NeoForge.
