Modrinth is an open‑source modding platform for Java Edition only, supporting Forge, Fabric, Quilt, and NeoForge. It has no fake download buttons and shares ad revenue with creators.

⚡ Quick Start
Search mod → check MC version & loader → Versions tab → click Download (.jar for mods, .zip for packs) → place .jar in .minecraft/mods → launch with correct loader profile. Or use the free Modrinth App for auto‑install.

📥 Download Steps

1. Go to modrinth.com and find a mod.
2. On the project page, verify the Minecraft version, mod loader (Forge/Fabric/Quilt/NeoForge), and environment (Client/Both).
3. Open the Versions tab and locate the file matching your setup.
4. Click Download – mods save as .jar, resource/data packs as .zip.
5. Open your .minecraft folder:
   · Windows: Win+R → %appdata%\.minecraft
   · macOS: Cmd+Shift+G → ~/Library/Application Support/minecraft
   · Linux: ~/.minecraft
6. Create a mods folder (lowercase) if missing – place the .jar inside. For .zip packs: place in resourcepacks or saves/<world>/datapacks.
7. Launch Minecraft using the matching mod loader profile; mods appear in the Mods menu.
8. Easiest method: Install the free Modrinth App from modrinth.com/app – it manages dependencies, versions, and installs automatically.

❗ Common Problems

Problem Solution
Mod doesn't work Check loader (Fabric ≠ Forge), MC version, and Relations tab for dependencies (e.g., Fabric API).
Game crashes on launch Remove mods one by one; ensure all are for the same version.
Downloaded .zip instead of .jar Keep it – place in resourcepacks or datapacks.
Don't know which loader Look at your launcher profile name (Forge, Fabric, etc.).
App can't connect Check internet, restart app, or reinstall from the official site.

⚠️ Important Warnings

· Java Edition only – no Bedrock support.
· Never double‑click .jar files – just place them in the mods folder.
· Always check Relations for required dependency mods.
· Only download from modrinth.com – avoid repacks.
· The Modrinth App is completely free – never pay for imposters.
