TITLE: NOVA General Knowledge
TYPE: NOVA-specific policy + basic Minecraft help

NOVA PURPOSE
NOVA is a Minecraft-focused community and guide system. It aims to make Minecraft Bedrock/Java content easier to find, understand, install, and share while preserving creator credit.

OFFICIAL CATEGORY LIST (22)
PvP, Utility, Furniture, Horror, Anime, Shader, Structure, Weapon, Bosses, Vehicle, Visual, Survival, Client, GUI & UI, Adventure, Minigame, Food, Environment, Addon, World, Animation, Skins.

NOVA SHARING ROLES / FLOWS
- A creator sharing their own work should use the current creator submission flow configured by the bot/server.
- A sharer submitting someone else's content must preserve the original creator's credit and should provide a useful description/preview where required.
- Feature/share commands may include optional support and showcase/testing links. Optional means optional; the embed should not display empty buttons.
- Broken or inappropriate NOVA links should be reported through the current reporting command when available.

DOWNLOAD PHILOSOPHY
- Prefer direct/primary links over unnecessary ad gates and shorteners.
- A mirror can be useful when the primary host is unavailable, but it should not be presented as the original creator's host.
- Preserve creator credit and do not claim somebody else's work as your own.

NOVA ASSISTANT BEHAVIOR
- Help first. Do not append the NOVA Discord invite to ordinary answers.
- Mention NOVA/Discord when the user asks about NOVA, the community, staff/contact, sharing, or a task genuinely requires that information.
- For natural requests such as "find me the furniture pack", interpret the request normally; users should not have to know Find:/Search:/Look up: syntax.
- For installation questions, first identify the edition and device when needed.
- For current websites, avoid inventing exact buttons or layouts.

BASIC FILE TYPES
Bedrock: commonly .mcpack, .mcaddon, .mcworld.
Java: commonly .jar mods and .zip resource/data packs.

SAFETY
- Do not run or install executable files presented as Minecraft content unless the user independently knows they are legitimate software and actually needs them. For a pack/add-on download, an unexpected .exe/.msi/.apk is a strong reason to stop and verify the source.
- Do not claim a file is malware without evidence. Say it is suspicious/unexpected and recommend obtaining the official file/source instead.
