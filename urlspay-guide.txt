Urlspay is a URL shortener forcing multiple unlock rounds before the final link. NOVA never uses Urlspay — direct links only.

⚡ Quick Start
Open in Chrome (not in-app) → Continue to Content → wait ~20s → Unlock Link → scroll down → Verify → Continue. Repeat 3–5 rounds until redirected to the file host.

🔓 Steps
1. Open the link in Chrome or Safari — avoid in-app browsers (Discord, YouTube, TikTok).
2. Click Continue to Content.
3. Wait ~20 seconds on the page — don't switch tabs or let the screen sleep.
4. Tap Unlock Link once active, then scroll to the very bottom.
5. Tap Verify, then Continue once it appears.
6. Repeat steps 3–5 for 3–5 rounds (occasionally up to 7).
7. After the final round, tap Unlock Link → scroll down → Continue/Get Link.
8. You'll land on the real file host (MediaFire, Google Drive, MEGA, etc.).

❗ Common Problems
· Page reloads/progress resets → use Chrome or an external browser; in-app browsers break sessions.
· Countdown restarts → stay on the page, don't switch tabs.
· Can't find Verify → scroll to the very bottom, or rotate to landscape.
· All rounds done but no link → may need up to 7 rounds; if it still fails, request a direct link.
· "Virus detected" pop-up or install prompt → fake ad — close the tab, don't click anything.

⚠️ Warnings
· Never pay, enter personal info, or install anything.
· Never click banner ads or pop-ups.
· Ad blockers may break the unlock — disable temporarily if needed, then re-enable.
· Use Chrome or Safari — in-app browsers cause failures.

❓ FAQ
Q: Why doesn't NOVA use Urlspay? A: NOVA only shares direct links — no ad walls or shorteners.
Q: Found one in NOVA? A: Report it with /nova-report.
