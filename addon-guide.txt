NOVA Download & Installation Guide

⚡ Quick Start
· Bedrock: download .mcpack/.mcaddon/.mcworld/.mcskin → tap file → open with Minecraft → activate in world settings.
· Java: install a mod loader (Fabric, NeoForge or Forge) → place .jar in .minecraft/mods → select the loader profile in your launcher.

📋 Minecraft versions (2026)
Since 2026 Minecraft versions are year-based. Java 26.1 (March 2026) matches Bedrock 26.10; Java 26.2 followed. Bedrock hotfix numbers differ from Java's, so compare against the edition you play. Packs and mods list the versions they support — pick the file for your version. Java Edition 26.1 and newer needs Java 25.

📱 Bedrock Installation
1. Check the extension: .mcpack, .mcaddon, .mcworld, .mcskin. Never open .exe, .apk, or .msi.
2. Download from a trusted source: MCPEDL, CurseForge, or the NOVA Discord (https://discord.gg/Zc5pPEZYpe).
3. Open a file manager (ZArchiver on Android) → Downloads → tap the file. On Windows, double-click the file.
4. If it's a .zip, rename it to .mcpack/.mcaddon.
5. Open with Minecraft → wait for "Successfully Imported."
6. In your world: Resource Packs / Behaviour Packs → move the pack to Active. For .mcaddon, activate both.
7. Enable Experimental Gameplay if the pack requires it (World Settings → Experiments).
8. Some add-ons come as two files (behaviour pack and resource pack, often marked BP and RP) — install both.

💻 Java Installation
1. Install a mod loader matching your MC version: Fabric (fabricmc.net), NeoForge (neoforged.net) or Forge (files.minecraftforge.net). Quilt had no 26.1+ builds as of mid-2026. The CurseForge app and the Modrinth App can set up loaders and mods for you (Java only).
2. Open .minecraft: Windows Win+R → %appdata%\.minecraft · macOS Cmd+Shift+G → ~/Library/Application Support/minecraft · Linux ~/.minecraft
3. Create a lowercase "mods" folder if missing, then place the .jar inside — don't double-click it.
4. Launch with the matching loader profile; the mod appears in the Mods menu.
5. Resource packs: Options → Resource Packs → Open Pack Folder → drop the .zip in (don't extract).
6. Datapacks: place the .zip in saves/<world>/datapacks, then run /reload.
7. Worlds: extract the .zip and move the folder into .minecraft/saves.

❗ Common Problems
· Import failed → use "Open with" Minecraft; rename .zip to .mcpack.
· Pack not showing → activate both packs, enable Experimental Gameplay.
· Add-on only half works → one of its two files (BP/RP) is missing; install both.
· Java crash → match mod version to your MC version exactly; check dependencies (e.g. Fabric API); 26.1+ needs Java 25.
· .exe/.apk file → delete immediately, report in NOVA Discord.
· No "mods" folder → create one (lowercase) in .minecraft.

⚠️ Warnings
· Never open .exe/.apk/.msi files.
· Only download from trusted sites.
· Bedrock files and Java files are not interchangeable.
· Activate both packs for .mcaddon.
· Check mod dependencies before launching.

❓ FAQ
Q: Can I use Bedrock addons on Java? A: No.
Q: How do I install Fabric/NeoForge/Forge? A: Download the installer, run it, and pick your MC version.
Q: Why is my Minecraft version 26.x? A: 2026 versions start with the year (26.1, 26.2…).
