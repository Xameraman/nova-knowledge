NOVA Download & Installation Guide

⚡ Quick Start
· Bedrock: Download .mcpack / .mcaddon / .mcworld / .mcskin → tap file → open with Minecraft → activate packs in world settings.
· Java: Install Forge or Fabric → place .jar mods in .minecraft/mods folder → select mod loader profile in launcher.

📱 BEDROCK INSTALLATION
1. Check file extension: .mcpack, .mcaddon, .mcworld, .mcskin. Never open .exe, .apk, .msi!
2. Download from trusted sources: MCPEDL, CurseForge, NOVA Discord (https://discord.gg/Zc5pPEZYpe).
3. Open file manager (ZArchiver on Android) → Downloads folder → tap file.
4. If .zip, rename to .mcpack/.mcaddon.
5. Open with Minecraft → "Import Started" → "Successfully Imported".
6. Create/edit world → Resource Packs / Behaviour Packs → move pack to Active column.
   For .mcaddon: activate BOTH behaviour and resource pack.
7. Enable Experimental Gameplay if needed (World Settings → Experiments).
8. Test in world.

💻 JAVA INSTALLATION
1. Install mod loader: Forge (files.minecraftforge.net) or Fabric (fabricmc.net) – match your MC version.
2. Open .minecraft folder:
   - Windows: Win+R, %appdata%\.minecraft
   - macOS: Cmd+Shift+G, ~/Library/Application Support/minecraft
   - Linux: ~/.minecraft
3. Create "mods" folder (lowercase) inside .minecraft if missing.
4. Place .jar mod file into mods folder. Do NOT double-click.
5. Launch Minecraft with Forge/Fabric profile → mod appears in Mods menu.
6. Resource packs: Options → Resource Packs → Open Pack Folder → place .zip there (do not extract).
7. Datapacks: place .zip in saves/worldname/datapacks, then run /reload.
8. Worlds: extract downloaded .zip, move folder into .minecraft/saves.

❗ COMMON PROBLEMS
- Import failed → use "Open with" Minecraft, rename .zip to .mcpack.
- Pack not showing → activate both packs, enable Experimental Gameplay.
- Java crash → check mod version matches Minecraft exactly; check dependencies (Fabric API, etc.).
- .exe/.apk file → DELETE immediately, report in NOVA Discord.
- No "mods" folder → create it (lowercase) inside .minecraft.
- .zip should be .mcpack → rename extension.

⚠️ WARNINGS
· Never open .exe/.apk/.msi files.
· Only download from trusted sites.
· Bedrock files ≠ Java files.
· Keep .zip resource packs/datapacks compressed.
· Check mod dependencies.
· For .mcaddon, activate both packs.

❓ FAQ
Q: Can I use Bedrock addons on Java? A: No.
Q: How to know if mod is Fabric/Forge? A: Check download page.
Q: How to install Forge/Fabric? A: Download installer, run, pick MC version.
Q: Why need mod loader? A: Mods won't work without it.
