NOVA Download & Installation Guide

QUICK START
- Bedrock: download a valid .mcpack/.mcaddon/.mcworld/.mcskin file, open it with Minecraft, then activate the required packs in the intended world.
- Java: install a compatible mod loader, place .jar mods in .minecraft/mods, and launch the matching loader profile.

MINECRAFT BEDROCK INSTALLATION
1. Check the file extension: .mcpack, .mcaddon, .mcworld, and .mcskin are recognized Minecraft-related package formats. Never open unexpected .exe, .apk, or .msi files as Minecraft packs.
2. Download content from a source you trust, and check the creator's version requirements.
3. On Android, open the Downloads folder in a file manager and tap a recognized Minecraft package file. Choose Minecraft if prompted and wait for the import confirmation.
4. ZIP FILES — DO NOT RENAME AUTOMATICALLY. A .zip extension alone does not reveal whether its contents are a valid Minecraft pack or a bundle. Inspect the archive and follow the creator's instructions first.
   - .mcpack is a ZIP-formatted resource pack or behavior pack.
   - .mcaddon is a ZIP-format bundle containing .mcpack or .mcworld files, and is generally used to distribute add-ons.
   - .mcworld is a ZIP archive containing the files for a Minecraft Bedrock world.
   - If the ZIP contains ordinary folders, loose files, multiple packages, documentation, or an unclear structure, do not guess the extension. Extract it only when appropriate and use the creator's documented installation procedure.
5. After importing, activate the required resource and/or behavior packs in the world settings where you intend to use them. Importing does not automatically activate a pack in every world. A linked resource pack may be activated automatically when its behavior pack dependency is enabled, but do not promise this for every add-on.
6. Enable Experimental Gameplay only when the creator's page says it is required.
7. Some add-ons include separate behavior-pack (BP) and resource-pack (RP) files. Import and activate both when the creator says both are required.

JAVA EDITION INSTALLATION
1. Use a mod loader compatible with both the Minecraft version and the mod.
2. Open the .minecraft directory and create the lowercase mods folder if needed.
3. Place the .jar file in the mods folder; do not double-click it to install it.
4. Launch the matching loader profile and check the mod list.
5. Resource packs may be distributed as ZIP files and generally should retain their documented format. Java worlds and datapacks have their own folder requirements; do not apply Bedrock file-extension advice to Java content.

COMMON PROBLEMS
- File downloaded as .zip: do not blindly rename it to .mcpack or .mcaddon; inspect its contents and creator instructions.
- Import failed: confirm that it is a valid Minecraft package, check the extension against its actual contents, and choose Open with Minecraft where appropriate.
- Pack not showing in a world: activate the required resource and behavior packs in that world's settings; enable required experiments.
- Add-on only partly works: check whether the creator requires both behavior-pack and resource-pack files.
- Java mod crash: check exact Minecraft version, loader compatibility, and dependencies.
- Never open unexpected executable or app-installer files as Minecraft packs.

CORE FILE EXTENSION DEFINITIONS
- .mcpack: a zipped Bedrock resource pack or behavior pack.
- .mcaddon: a ZIP bundle containing .mcpack or .mcworld files; generally used to distribute add-ons.
- .mcworld: a ZIP archive containing a Bedrock world.
These definitions describe formats, not a guarantee that any arbitrary ZIP archive can safely be renamed. The internal structure and creator's instructions matter.
