Linkvertise is a link-monetization gateway requiring free tasks before unlocking a download. NOVA never uses Linkvertise — this guide is only for links you encounter elsewhere.

⚡ Quick Start
Open in Chrome/Firefox → main button → Free Access with Ads → complete tasks (keep tabs open, wait, captcha) → Continue → download from the final host.

🔓 Steps
1. Open the link in Chrome, Firefox, or Edge — avoid in-app browsers (Discord, YouTube).
2. Wait for the gateway page; a countdown may run before the main button is clickable.
3. Click the main button, then choose Free Access with Ads — never pay.
4. Complete any captcha (disable VPNs temporarily if it fails).
5. Complete the 1–4 assigned tasks: waiting on a sponsored page (10–15s, no clicking), watching/skipping a video ad, keeping an article tab open until the timer ends, a search-and-click task, follow/subscribe (look for Skip first), or an app-store open (close immediately, no install needed).
6. Once every task shows complete, click Continue/Get Access.
7. You'll land on the real file host (MediaFire, Google Drive, MEGA, etc.) — download there.

❗ Common Problems
· "Invalid Visit Detected" → disable VPN, switch network, try another browser.
· Page loads forever → disable ad blockers/extensions, clear cache.
· Continue stays grey → scroll for unfinished tasks; don't refresh (resets progress).
· Tasks won't register → wait longer on each page; confirm you clicked the required button.
· Install prompt appears → never install; close it and look for Skip.

⚠️ Warnings
· Never install apps/extensions/software from task pages.
· Only interact with the main button and task elements — never banner ads.
· Never enter payment or personal info; it's always free.
· Don't use in-app browsers, and never refresh mid-process (progress resets).
· NOVA requires direct links — report any Linkvertise link with /nova-report.

❓ FAQ
Q: Do I ever pay or install anything? A: No — opening an app-store page is the max required, never install.
Q: Does NOVA allow Linkvertise? A: No — report it with /nova-report.
