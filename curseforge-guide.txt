CurseForge Download & Installation Guide

CurseForge is the largest modding platform for Minecraft, hosting mods, modpacks, resource packs, shaders, data packs, worlds, and add‑ons for both Java and Bedrock editions.

⚡ Quick Start
· Java: Search mod → check version & loader → download .jar → place in .minecraft/mods → launch with Forge/Fabric.
· Bedrock: Browse Bedrock section → download .mcpack/.mcaddon → tap file → open with Minecraft → activate in world settings.

💻 JAVA DOWNLOAD STEPS
1. Go to curseforge.com/minecraft. Search for mod. Look for Verified badge.
2. Check compatibility: MC version, mod loader (Forge/Fabric), and dependencies (Relations tab).
3. Click Files tab, find correct version, click ⋯ → Download File. Wait for 5‑second countdown.
4. Place .jar in .minecraft/mods folder (create mods if missing). Launch with mod loader profile.

📱 BEDROCK DOWNLOAD STEPS
1. Go to curseforge.com/minecraft-bedrock. Browse or search.
2. Ensure file is .mcpack, .mcaddon, .mcworld, or .mcskin. .jar = Java only!
3. Click Files tab → Download. Wait for countdown.
4. Open file manager → tap file → open with Minecraft → import.
5. Activate packs in world settings (both behaviour & resource for .mcaddon).
6. Enable Experimental Gameplay if needed.

❗ COMMON PROBLEMS
- Mod not appearing (Java) → check mods folder, loader version, missing dependencies.
- Game crash → remove mods one by one, check dependencies, update Java.
- Import failed (Bedrock) → rename .zip to .mcpack, use "Open with" Minecraft.
- Pack not working → activate both packs, enable Experimental Gameplay.
- Countdown doesn't start → refresh page, avoid ads.
- Dependency missing → check Relations tab on CurseForge.

⚠️ WARNINGS
· Only download from curseforge.com.
· Never click banner ads – real button is inside Files tab.
· Java .jar ≠ Bedrock .mcpack.
· Check dependencies before downloading.
· Do not double‑click .jar files.

❓ FAQ
Q: Is CurseForge free? A: Yes.
Q: Is it safe? A: Yes, files are scanned.
Q: Difference between Java and Bedrock? A: Java uses .jar + mod loaders; Bedrock uses .mcpack/.mcaddon.
Q: How do creators earn? A: Author Rewards Program via downloads.
